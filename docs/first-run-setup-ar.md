# إعداد أول تشغيل — وكالة واحدة

## المسار
/login يحوّل إلى /setup فقط إذا قاعدة التثبيت فارغة، جدول agency_profiles موجود، وكود التثبيت مفعّل.
خطوتان: كود التثبيت وحساب الجيران؛ ثم اسم الوكالة والعنوان والهاتف والإيميل واللوغو والمعلومات القانونية الاختيارية.
لا بيانات سيارات أو عملاء أو أداءات أو عقود تُنسخ من التجارب.
بعد النجاح يرجع المستخدم للدخول بحسابه. إنشاء الوكالة والحساب والملف القانوني وإعداد التحضير وسجل التأسيس في معاملة واحدة.

## الحماية
- INSTALLATION_TOKEN_HASH: بصمة SHA-256 لكود عشوائي قوي يسلمه المثبّت لصاحب الوكالة عبر قناة خاصة.
- الافتراضي فارغ: التثبيت مغلق. لا تسجيل عام ولا إنشاء وكالات متعددة.
- وجود أي وكالة أو مستخدم يغلق التثبيت. لا إعادة تعيين ولا حذف من هذه الصفحة.
- قفل companies نفسه في CLI وHTTP يمنع إنشاء مسؤولين متنافسين.
- POST تحت CSRF وthrottle؛ لا يوجد تجاوز عبر GET.
- رمز التفعيل وكلمات السر لا تضاف للـURL أو التخزين المحلي للمتصفح.
- اللوغو صورة PNG/JPEG/WebP فقط حتى 1Mo؛ محفوظ مع قاعدة البيانات داخل agency_profiles.
- معلومات الوثائق تستعمل agency_profiles مع الإبقاء على الملف الخاص القديم للبيئات الموجودة.
- لم تتغير صلاحيات الموظفين أو قواعد الأداء والعقود.

## تثبيت جديد على السيرفر
1. قاعدة PostgreSQL فارغة جديدة مع btree_gist، ومستخدم DB خاص بها.
2. إعداد APP_KEY جديد وإعدادات النطاق وHTTPS وcookies وCORS.
3. تشغيل migrations على القاعدة الجديدة فقط، دون seed للديمو.
4. توليد كود عشوائي من 32 بايت على الأقل، ووضع SHA-256 دياله في INSTALLATION_TOKEN_HASH. تسليم الكود بشكل خاص.
5. فتح /login وإتمام الإعداد ثم الدخول.
6. إزالة INSTALLATION_TOKEN_HASH بعد النجاح وإعادة بناء config cache.
إعداد الوكالة لا يفعّل وحده إصدار العقود والفواتير النهائية؛ هاد المرحلة مستقلة.
