# لائحة تجهيزات الوكالة

- جدول `vehicle_equipment_catalog` منفصل حسب `company_id`، مع مفتاح اسم موحد يمنع التكرار حتى مع اختلاف الحروف الكبيرة أو المسافات.
- زر Ajouter يحفظ التجهيز مباشرة في لائحة الوكالة، حتى إذا أُغلق نموذج السيارة. اختيار تجهيزات السيارة يبقى محفوظاً عند تسجيل السيارة.
- نزع الاختيار يزيل التجهيز من السيارة فقط؛ لا يحذفه من اللائحة المشتركة.
- الاحتفاظ بربط الاختيارات عبر `vehicles.custom_equipment` الحالي يمنع تغيير عقد API أو محتوى الموقع أو البيانات القديمة. لا حاجة إلى جدول pivot مكرر في هذه المرحلة.
- الترحيل يستخرج تجهيزات السيارات القديمة ويحتفظ بترجماتها دون تعديل أي سيارة أو مستند صادر. حفظ السيارة يسجل أيضاً التجهيزات المرسلة عبر العملاء السابقين.
- واجهتا GET/POST vehicles/equipment-catalog تحت نفس مصادقة وسياق الوكالة لإدارة السيارات. لا صلاحية إدارية جديدة.

## تعديل وإخفاء التجهيزات
- Modifier يغيّر لائحة الاختيارات فقط؛ السيارات تبقى محتفظة بأسماء تجهيزاتها المسجلة. الاسم القديم يبقى كسجل مؤرشف حتى لا يرجع تلقائياً عند حفظ سيارة قديمة.
- Retirer de la liste يؤرشف الاختيار بعد تأكيد، ولا يمس بيانات السيارات. إضافة نفس الاسم صراحةً يمكن أن تعيد إظهاره.
- منع التعارض عند تعديل اسم تغيّر أو أُرشف من جلسة أخرى؛ رفض اسم نشط مكرر. العزل حسب الوكالة في جميع العمليات.
