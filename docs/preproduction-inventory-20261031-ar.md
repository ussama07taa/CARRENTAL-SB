# جرد البيانات واختبار الاسترجاع قبل الانتقال للاستعمال الحقيقي

## النتيجة
تم حفظ واسترجاع قاعدة الخدمة المحلية bensebih_pickup_sandbox_20261019 في PostgreSQL 16 مستقل بلا اتصال TCP، ثم إيقافه.
لم يتم حذف أو تعديل سجلات المصدر، ولا تشغيل ترحيلات أو تحويل وضع التشغيل.

- 90 جدولاً، 2524 سجلاً: العدد ومحتوى كل جدول مطابقان عبر SHA-256.
- 239 ملفاً، 38,217,051 بايت: الصور والوثائق المسترجعة مطابقة بايتاً ببايت.
- قيود العلاقات والفهارس مطابقة بعد الاسترجاع.
- بصمات الأرشيفات أعيد فحصها بنجاح.
- مفتاح التطبيق والإعدادات محفوظان في environment.private داخل النسخة الخاصة، المستثناة من Git.

## الفرز قبل الانتقال
مطابقة أولية للأسماء واللوحات رصدت علامات TEST / DEMO / fictif / parcours في 33 عميلاً و35 سيارة.
هذا مؤشر للمراجعة فقط: وجود DEMO في لوحة سيارة لا يعني أن معلومات السيارة كلها غير حقيقية، وغياب العلامة لا يثبت صحة السجل.
لا نقل آلي إلى الإنتاج، ولا تحويل الأداءات التجريبية إلى تحصيل حقيقي، ولا حذف التاريخ.
نحتاج اعتماد قائمة العملاء والسيارات الصحيحة مع المستخدم قبل تجهيز قاعدة الإنتاج.

## نطاق وحدود التحقق
هذه نسخة قاعدة الخدمة المحلية النشطة وstorage/app وكود API/dashboard المشغل وإعدادات API.
ليست جرداً لكل قواعد PostgreSQL الأخرى ولا نسخة كاملة لنظام التشغيل أو الموقع العام.
نجاح الاسترجاع مثبت للبيانات والملفات والقيود؛ لم يُنفذ اختبار دخول وتشغيل كامل للتطبيق المسترجع.
النسخة محلية على نفس الجهاز، وليست بعد نسخة خارجية مشفرة.
لم يتم تفعيل العقود الحقيقية أو تغيير وضع demo.
