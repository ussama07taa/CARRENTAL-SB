# استيراد وتصدير Excel — السيارات والزبناء

## الاتفاق
- موافقة المستخدم في 30 أكتوبر 2026: المسؤول والخدّام بجوج يقدرو يستوردو ويصدّرو، داخل صلاحياتهم ووكالتهم الحالية.
- المرحلة الحالية: السيارات والزبناء فقط؛ لا استيراد للأثمنة، الأداءات، العقود، الفواتير أو النشر العمومي. المسؤول يحدد الثمن من المسار الموجود بعد إنشاء السيارة.

## المسار
- زر التصدير كيخرج ملف `.xlsx` بجميع الصفحات الموافقة لنفس البحث والفلاتر، والحقول الظاهرة فاللائحة فقط. سقف تقني 10 آلاف سطر، مع طلب تضييق الفلاتر عند تجاوزه.
- الاستيراد: تنزيل نموذج منفصل، رفعه، معاينة جميع الأسطر والأخطاء، ثم تأكيد صريح. سقف 500 سطر و2 ميغابايت، ورفض الصيغ والأعمدة الإضافية. ورقة Instructions فيها الإرشادات.
- الإدخال كيخلق ملفات جديدة فقط. التكرار فالملف أو فالوكالة كيوقف الدفعة كاملة، بدون استبدال أو حذف. العميل: الاسم الكامل أو الهاتف أو الهوية؛ السيارة: اللوحة أو الشاسيه.
- معاينة مشفرة مرتبطة بالمستخدم والوكالة ونوع البيانات، صالحة 30 دقيقة. التأكيد يعيد فحص التكرار تحت قفل الوكالة، داخل transaction واحدة، ويستعمل مفاتيح الإنشاء الموجودة لمنع التكرار عند إعادة المحاولة.
- أحداث `excel_imported` كتزيد فالسجل الموجود غير القابل للتعديل: الفاعل، الوقت، بصمة الملف، رقم السطر ومرجع الملف المنشأ. ملف Excel الخام ما كيتخزّنش بشكل دائم.
- لا migration ولا صلاحيات جديدة في قاعدة البيانات؛ كتستعمل نفس حماية العضوية ومسارات الحفظ الحالية.

## التحقق
- `php artisan test --filter=ExcelExchangeTest`: معاينة، حفظ، إعادة محاولة، رفض التكرار، السباق بين المعاينة والتأكيد، العزل، انتهاء المعاينة، منع أعمدة الثمن، التصدير بكل الصفحات حسب الفلاتر، وعدم تنفيذ الصيغ.
- مراجعة المتصفح بحساب المسؤول والخدّام: تنزيل النموذج والتصدير، معاينة صحيحة وأخرى مكررة، وعروض 1536 و390 و320 بكسل. اختبارات الإدخال الفعلي في PostgreSQL المخصص للاختبارات؛ فحص الواجهة لا يضيف بيانات تجريبية للوكالة.

## إضافة تاريخ الصيانة — 30 أكتوبر 2026
- موافقة المستخدم على البدء بالصيانة: الاستيراد متاح للمسؤول والخدّام من Entretien & suivi. تصدير الصيانة متاح أيضاً حسب البحث والتبويب المختار وبكل الصفحات. تصدير الخدّام لا يحتوي أعمدة مالية؛ المسؤول يشوف نفس مبالغ اللائحة مع حالة الكلفة المؤقتة أو غير المحددة.
- النموذج: اللوحة، تاريخ الإنجاز، النوع، التدخل، الكيلومترات، الكراج، الملاحظات. السيارة خاصها تكون موجودة فالوكالة. كل سطر تدخل منجز، بلا مواعيد مستقبلية.
- الربط بالسيارة محفوظ من المعاينة؛ إذا تغيرت ملكية اللوحة داخل البيانات قبل التأكيد، خاص إعادة المعاينة. التكرار حسب السيارة والتاريخ والنوع والعنوان، مع فحص التدخلات وأعمال الملفات الموجودة.
- التسجيل يستعمل maintenance_work_items بحالة done وكلفة unknown/NULL، لا ثمن مؤكد صفر. لا أداء ولا مصروف جديد، لا تغيير للعداد الحالي ولا للحجز أو الجاهزية ولا إنهاء زيارة كراج مفتوحة.
- سجل maintenance_excel_imported يحتفظ بالفاعل والوقت وبصمة الملف والسطر ورقم التدخل. إعادة التأكيد لا تكرر التدخل. لا migration.
- التحقق: استيراد وحفظ فعلي لكلا الدورين في PostgreSQL الاختبار، مع ثبات العداد والكراج وعدم إنشاء أداءات أو مصاريف؛ رفض التكرار والسيارة خارج الوكالة والتاريخ المستقبلي وأعمدة المال؛ فحص السباق وتغيير ربط اللوحة.
