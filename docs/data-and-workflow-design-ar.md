## القرارات اللي نبنيو عليها

Laravel هو المرجع لقواعد العمل، مع موقع Next.js ولوحة Next.js بــTypeScript داخل مستودع واحد، وPostgreSQL قاعدة البيانات. الموقع بالعربية والفرنسية واللوحة بالفرنسية فقط.

تأكيد الحجز كيحتاج كامل مبلغ الكراء. الضمان منفصل ومتغير حسب الاتفاق، والموظف يقدر يحدد قيمته؛ الإعفاء والاقتطاع يحتاجو المسؤول. اليوم أربع وعشرون ساعة، وحتى اثنتي عشرة ساعة نصف يوم بنصف الثمن؛ الباقي من بعد الأيام الكاملة كيتحسب بنفس الطريقة.

الحجز المستقبلي مسموح بعد الرجوع المتوقع والتحضير، مع المنع بعد التأخر ومراجعة المسؤول للكراء المفتوح. التحضير ساعتان افتراضياً، والمسؤول يضبط المدة، والجاهزية الفعلية ضرورية قبل التسليم.

## خريطة مجموعات البيانات

### الوكالة والمستخدمون والزبناء

| المجموعة | المعطيات الأساسية والعلاقة |
|---|---|
| الوكالة وإعداداتها | الهوية، العملة، المنطقة الزمنية، قواعد العمل بإصداراتها، ومعلومات الفوترة بعد تأكيدها |
| المستخدمون والصلاحيات | حساب فردي، عضوية الوكالة، الدور، الحالة، الجلسات وسجل القرارات |
| الأشخاص | بيانات صاحب الكراء والسائقين، التواصل، التحقق؛ الهاتف قابل للاشتراك وماشي مفتاح هوية وحيد |
| سائقو الحجز | ربط كل سائق بالكراء، صفته، وصلاحية وثائقه وقت التحقق |
| الملاحظات والمنع | الملاحظة، صاحبها، التاريخ، سبب المنع أو رفعه؛ خلاف مفتوح ما يساويش منعاً تلقائياً |

التحقق من أصل وثيقة يتسجل حتى إذا ما تحفطاتش صورتها. الصور غير المطلوبة ما نجمعوهاش. نطاق الاحتفاظ والوصول كيتحدد حسب المتطلبات المؤكدة.

### السيارات والتسعير

| المجموعة | المعطيات الأساسية والعلاقة |
|---|---|
| أنواع السيارات | وصف مترجم وتجهيزات وصور، وإعداد الأثمنة وحصة الكيلومترات |
| السيارات الفعلية | النوع، اللوحة، رقم الهيكل، حالة الخدمة والعداد؛ السيارة ما تتبدلش هويتها داخل التاريخ |
| قراءات العداد | قيمة ووقت ومصدر القراءة والفحص المرتبط؛ التصحيح يحتافظ بسبب وأثر القراءة القديمة |
| فترات الأثمنة | النوع، البداية والنهاية، الثمن اليومي؛ منع التعارض غير المحسوم لنفس النوع |
| وثائق السيارة | نوع الوثيقة، بداية ونهاية الصلاحية، الملف، والإصدارات السابقة |
| تدخلات الصيانة | السبب، المواعيد والعداد والأشغال والمرأب والإنجاز؛ التكلفة مرتبطة بالمصروف الأصلي |
| التوقفات | السبب، الوقت المخطط والفعلي، التأكيد بالجاهزية والملفات المرتبطة |

إعداد جديد للأثمنة أو التحضير ما يبدلش اتفاقات قديمة. نفس الشي لحصة الكيلومترات وتعريفة التجاوز.

### الحجز والكراء والتوفر

| المجموعة | المعطيات الأساسية والعلاقة |
|---|---|
| الحجز | المرجع، المصدر، الشخص، اللغة، النوع، المواعيد، المرحلة، موعد انتهاء الحجز المؤقت، وعلامة الكراء المفتوح |
| نسخ العرض والاتفاق | تفصيل المدة والثمن والشروط المقبولة، الحصة وتعريفة التجاوز، نسخة سياسة الإلغاء والتأخير والتحضير |
| بنود المستحقات | المبلغ بالسنتيم، الكمية أو الفترة، السبب، تاريخ الاعتماد، العملية التي أنشأته؛ لا إعادة كتابة لبند مؤكد |
| تخصيصات السيارات | السيارة، الفترة المخططة، فترة الاستعمال الفعلي، فحص الخروج والرجوع، وسبب التبديل |
| فترات الإشغال | السيارة، الفترة المانعة، المصدر، وحالة المنع؛ المصدر حجز أو صيانة أو تحضير |
| الفحوص | خروج أو رجوع، الوقت، العداد، الوقود، الملاحظات والصور وصاحب التحقق |
| التعديلات | طلب تمديد أو تغيير موعد أو سيارة، نسخة قبل وبعد، فرق الثمن، موافقة الزبون واعتماد المسؤول عند الحاجة |
| أحداث الكراء | سجل يضاف إليه: انتقال مرحلة، اتصال، تمديد، رجوع، اعتماد، مع صاحب العملية ووقتها |

السيارة الحالية فشاشة الكراء مستخرجة من التخصيص الجاري؛ ما نكتفيوش بتبديل معرف السيارة ونضيعو السابقة. لكل تبديل سجل يحدد شكون استعمل السيارة وفوقاش.

### الفلوس

| المجموعة | المعطيات الأساسية والعلاقة |
|---|---|
| أداءات الكراء | المبلغ، الطريقة، المرجع، الحالة، صاحب التسجيل والتحقق، معرف منع التكرار |
| إرجاعات أداءات الكراء | ارتباط بالأداء الأصلي، المبلغ والسبب والاعتماد والتنفيذ؛ مجموع الإرجاع ما يفوتش القابل للإرجاع |
| تخصيصات الأداء | ربط المال بالمستحق المقصود، مع منع توزيع أكثر من المتاح |
| اتفاق الضمان | المبلغ المطلوب، من حدده، طريقة الاستلام، أو إعفاء موثق |
| حركات الضمان | استلام، إرجاع، أو استعمال لتسوية مستحق معتمد؛ المخالف عليه مستقل عن المقتطع النهائي |
| حسابات المال | صندوق نقدي وحسابات بنكية حسب الحاجة؛ طريقة البطاقة ما تتحسبش نقداً فالصندوق |
| الحركات الفعلية | دخول أو خروج واحد لكل عملية منفذة، مع الأصل والطريقة والمرجع؛ منع نسخة مكررة من نفس المصدر |
| إقفالات الصندوق | البداية، الحركات، المتوقع، المعدود، الفرق، التسليم بين الموظفين والمراجعة |

هاد سجلات تسيير داخلي، ماشي التزام ببناء محاسبة عامة كاملة. عند تنفيذ أداء، الحركة الفعلية وتخصيصها والأثر على المستحق كيتسجلو فمعاملة واحدة. القرض والمصروف كيرتبطو بالحركة وما يكرروهاش.

قيمة الضمان المستلم التزام بالرد أو بالتسوية المعتمدة، ماشي دخل. اقتطاعه لتسوية ضرر ما يولدش قبضاً جديداً، وإرجاعه ما ينقصش من أداء الكراء.

### القروض والمصاريف والحوادث

| المجموعة | المعطيات الأساسية والعلاقة |
|---|---|
| عقود التمويل | السيارة، الجهة، الوثيقة، البداية، والمعلومات المعروفة من العقد بلا حساب فوائد مفترض |
| أقساط التمويل | تاريخ وقيمة كل استحقاق؛ قابلة للاختلاف داخل نفس القرض |
| تخصيص أداء الأقساط | المبلغ المخصص لكل قسط ومرجع الحركة الفعلية؛ يدعم أداء جزئياً أو توزيع أداء واحد |
| المصاريف وبنودها | الجهة والوثيقة والمبلغ والموعد، وتوزيع البنود على الوكالة أو السيارات |
| أداءات المصاريف | تخصيص حركات المال للمصاريف؛ الاستحقاق مستقل عن الأداء |
| ملف الحادث | الواقعة، السيارة والكراء عند وجوده، المسؤولية وأساسها، الصور والخبرة والإصلاح والتوقف |
| المطالبات والتعويضات | الجهة، المبلغ المتوقع أو المعتمد، المحصل، المرفوض أو المختلف عليه، والوثائق |
| المخالفات | وقت الواقعة، السيارة، المرجع، الكراء المقترح والمراجع، الاعتراض والأداء والتحصيل منفصلان |

فاتورة الإصلاح كتسجل كمصروف واحد، والملف كيشير ليها. التعويض المنتظر ما يتحولش لحركة مالية إلا عند التوصل الفعلي. نقص تعويض التأمين ما يخلقش مطالبة على الزبون آلياً.

|---|---|
| الملفات | المسار الخاص أو العام، النوع والحجم والبصمة ومالك الملف؛ ما نخزنوش رابطاً مؤقتاً كمرجع دائم |
| إصدارات العقود | بيانات وشروط ولغة مجمدة، الملف الأصلي، نسخة موقعة ووقت التحقق |
| الفواتير والأرصدة التصحيحية | الهوية والرقم والبنود المجمدة وحالة الإصدار، وربط التصحيح بأصله |
| العدادات | عداد لكل وكالة وسلسلة وسنة عند الحاجة، مع إصدار الوثيقة فالمعاملة نفسها |
| التواصل اليدوي | النص المحضر ولغته، الموظف، وقت التحضير وتأكيد الإرسال؛ فتح الرابط ما يساويش إرسالاً |
| سجل الوصول والقرارات | الفاعل والوقت والعملية والمرجع، بلا نسخ الوثائق الحساسة كاملة فالسجل |
| الأعمال الخلفية المطلوبة | إصدار وثيقة أو تنبيه، حالته ومحاولاته ومعرف يمنع تكرار النتيجة |

## العلاقات اللي خاص قاعدة البيانات تحميها

- كل سجل مهني مرتبط بالوكالة، وكل علاقة بين سجلين تابعين لوكالة تتأكد بمفتاح مركب يمنع الربط بين وكالتين.
- مراجع الحجوزات والفواتير والأداءات الخارجية ومعرفات منع التكرار عندها قواعد تفرد مناسبة داخل الوكالة.
- المبلغ يتخزن بالسنتيم الصحيح، بلا أعداد عائمة. المبالغ الموجبة والسالبة أو نوع الحركة كتتحدد صراحة، ما نخليوش معنى الإشارة يختلف بين المجالات.
- تاريخ النهاية بعد البداية؛ مدد الحجز المؤقت والتخصيص والتحضير ما تكونش فارغة أو غير محددة فحجز مؤكد.
- قيد منع تداخل الإشغال يشمل الفترات المانعة للحجوزات والصيانة والتحضير. الحالات المتوقعة غير المؤكدة ما تتحولش لإشغال بلا قرار.
- قواعد مجموع التخصيصات والإرجاعات والاقتطاعات كتحتاج قفلاً ومعاملة وفحصاً؛ مفتاح أجنبي بوحده ما كيحميش مجموع عدة أسطر.
- فحوص عدم التداخل والصلاحيات والأداء كتطبق على التأكيد والتمديد والتبديل والاسترجاع الإداري، ماشي على إنشاء الحجز فقط.
- ما نديروش حذفاً عادياً للحجوزات المؤكدة أو الحركات المالية. الإلغاء والتصحيح يحافظو على التاريخ؛ الاسترجاع الإداري النادر كيعيد فحص التعارض.

## مسار حالات الكراء المقترح للمراجعة

هاد تبسيط مقترح للمصفوفة التقنية، ماشي تغيير مطبق فالتعليمات القديمة. الاتصال ومحاولاته وحالة التحويل يمكن يتتبعو كمهام وسجلات مستقلة عوض فرض مرور كل زبون من مكالمة.

| من | إلى | الشرط والأثر |
|---|---|---|
| طلب | حجز مؤقت | تخصيص متاح، نسخة عرض، مهلة ساعتين وتبليغ الزبون |
| طلب | مؤكد | مسار الوكالة المباشر، توفر وأداء كامل متحقق منه واتفاق مثبت |
| طلب | ملغى | رفض أو تراجع أو انتهاء صلاحية الطلب وفق قاعدة موثقة؛ صلاحية الطلب ماشي مهلة الحجز المؤقت |
| حجز مؤقت | مؤكد | كامل الأداء المتحقق منه، مهلة صالحة وتوفر، وتجميد الاتفاق |
| حجز مؤقت | طلب | انتهاء المهلة؛ تحرير الإشغال والاحتفاظ بالطلب والأداءات إن وجدت، وحدث انتهاء لا يمسح التاريخ |
| حجز مؤقت | ملغى | إلغاء موثق وتحرير الإشغال وتسوية أي أداء |
| مؤكد | جارٍ | شروط الخروج كاملة وتأكيد التسليم الفعلي |
| مؤكد | ملغى | تطبيق الإلغاء وعدم الحضور وفق القاعدة؛ الإرجاع المالي يتتبع منفصلاً |
| جارٍ | راجع | الرجوع الفعلي والفحص مسجلان؛ التحضير والتوقف والتسوية يستمرو مستقلين |

التمديد والتبديل ما كيحتاجوش مرحلة كراء جديدة؛ كيزيدو سجلات اتفاق وتخصيص وبنوداً وأحداثاً، داخل معاملة صحيحة. الكراء اللي بدا ما يتلغاش باش نمسحو أثره؛ كيتسجل الرجوع والتسوية المناسبة.

اقتراح انتهاء الحجز المؤقت نحو الطلب يبقي إمكانية إعادة التفاوض، لكنه محتاج اعتماد المصفوفة قبل التنفيذ. إلى ذلك الحين، ما ننشئوش انتقالات خارج التعليمات الحالية فالكود. مدة صلاحية الطلب القديمة أربع وعشرون ساعة خاصها تمييز صريح عن مهلة الساعتين؛ ما نلغيهاش ضمنياً.

## حالات مستقلة عن مرحلة الكراء

| الجانب | الحالة اللي نحتاجو نعرفو |
|---|---|
| التسوية المالية | باقي على الزبون، مسوّى، مبلغ واجب الإرجاع، أو جزء مختلف عليه؛ مستخرجة من الحسابات لا تغيير يدوي للرصيد |
| الضمان | مطلوب أو معفى، مستلم، مردود جزئياً أو كلياً، مستعمل جزئياً أو كلياً، أو محتفظ بجزء مبرر |
| جاهزية السيارة | خارج الوكالة، رجعات وتنتظر التحضير، جاهزة، أو موقوفة بسبب أو أكثر |
| ملف الحادث | تقدم الإصلاح مستقل عن تقدم التحصيل والخلاف |
| التحويل | معلق، متحقق منه، فاشل أو ملغى؛ إرجاع المؤدى حركة مستقلة |
| القسط | مستحق ومؤدى جزئياً أو كلياً؛ التأخر مشتق من الوقت والباقي |
| الوثيقة | قيد الإصدار، صادرة، فشل توليد الملف، وموقعة عند التحقق؛ الفشل ما يستهلكش رقماً جديداً كل مرة |

الواجهة تقدر تعرض «الكراء رجع وباقي ألف درهم» بلا ما تبقى السيارة باينة مكتراة، و«السيارة تصلحات وتعويض التأمين باقي» بلا إغلاق زائف للملف.

## حدود المعاملات الحساسة

### تأكيد حجز

نقفل السجلات اللازمة بترتيب ثابت، نتحقق من الصلاحية والتوفر والمهلة والأداء المتحقق منه، نثبت الاتفاق والإشغال والمرحلة والحدث، ونسجل طلب إصدار الوثيقة. الكل ينجح أو يرجع. إنتاج الملف الثقيل كيجي من بعد، بمعرف ثابت لإعادة المحاولة.

هاد التراجع كيخص عملية التأكيد والتخصيص، ماشي واقعة التوصل بفلوس وصلات فعلاً. القبض المتحقق منه عندو سجل دائم ومعرف يمنع التكرار؛ إذا فشل التأكيد، المال يبقى غير مخصص أو محتاج تسوية واضحة. ما نمسحوش القبض بسبب رجوع معاملة الحجز.

### التمديد أو تغيير السيارة

نراجع العرض الجديد وموافقة الزبون والأداء والصلاحيات. نتحقق من الإشغال الجديد قبل تحرير القديم، ونعتمد التخصيص والبنود والحدث معاً. عند الفشل يبقى الحجز الأصلي. التجديد ما يكتبش فوق خطوط الثمن المجمدة.

### انتهاء المهلة مقابل وصول المال

المهمة الدورية وعملية التأكيد كيتزامنو على نفس الحجز. انقضاء المهلة ما يحذفش أداء وصل. إذا ما بقاش التوفر، المال يبقى ضمن المبالغ اللي خاصها معالجة بدل تأكيد غير صحيح أو إرجاع آلي غير معتمد.

### الرجوع والتحضير

نسجلو وقت الرجوع الفعلي والفحص ونهاية استعمال السيارة. فترة التحضير المخططة كتتراجع حسب الوقت الفعلي، مع الحفاظ على المدة المتفق عليها. إذا مدة التحضير الجديدة كتعارض حجزاً قائماً، ما نرفضوش تسجيل الحقيقة ولا نلغيو الحجز بصمت: نسجلو عدم الجاهزية ونفتح تنبيه تعارض للمعالجة، وقاعدة التسليم تمنع الخروج حتى الجاهزية.

هاد التمييز ضروري: قاعدة منع الحجوزات المتعارضة تحمي التخطيط، ولكن تأخر واقعي يقدر يكسر التوقع. تسجيل الواقع ما خاصوش يضيع بسبب رفض معاملة كتوسع فترة فوق حجز موجود.

### اقتطاع ضمان أو إرجاع مال

نقفل المبلغ الأصلي ورصيده القابل للاستعمال، نتحقق من الاعتماد ومنع التكرار، ونسجل الحركة والتخصيص والحدث. المبلغ المختلف عليه ما يتحولش لاقتطاع نهائي بدون اعتماد. موافقة المسؤول ما تعنيش أن المال ترد فعلاً؛ التنفيذ عندو تاريخ ومرجع.

عند الإلغاء، خاص تسوية المستحق الأصلي حسب سياسة الإلغاء، ثم تحديد المبلغ الواجب إرجاعه وتنفيذه. إرجاع المال بلا تعديل مستحق الكراء بالتسوية المناسبة كيخلق ديناً وهمياً. الأصل والبنود التصحيحية والوثائق المرتبطة كيبقاو محفوظين.

## الصلاحيات اللي التصميم كيحتاج يحافظ عليها

الموظف يسجل الطلب والزبون والفحص والأداء، يحدد مبلغ الضمان، ويستعمل الثمن والحصة المعتمدين. المسؤول يقرر تغيير الثمن والإعفاء والاقتطاع والإرجاع والتصحيح، ويشوف القروض والمالية العامة.

موظف عندو ملف كراء يقدر يشوف المبلغ اللازم لخدمتو، بلا كشف مجاميع الوكالة. الوصول للمستندات والتصدير وقرارات المنع ومراجعة الكراء المفتوح تتحدد فمصفوفة كاملة قبل التنفيذ. ما نفترضوش صلاحية غير منصوص عليها بسبب وجود زر فالتصميم.

## نقاط تنفيذية باقية وليست إعادة فتح للقرارات

- اعتماد أسماء ومصفوفة المراحل المبسطة مقابل المصفوفة القديمة، بما فيها انتهاء الحجز المؤقت.
- تحديد تقريب كسور السنتيم، وحدود المواسم فكراء يمتد عبر منتصف يوم، والثمن المرجعي للتأخير فكراء متعدد الأثمنة.
- الضرائب وترقيم الفواتير والبيانات الإلزامية مع المحاسب؛ الثمن المعروض إجمالي كما اتفقنا، بلا اختراع نسبة ضريبة.
- قواعد جمع وحفظ صور الهوية ومدد الاحتفاظ وموقع التخزين وفق المتطلبات المؤكدة. الأصل التحقق وتسجيل اللازم، بلا جمع صور احتياطي غير مبرر.
- اعتماد المصفوفة التفصيلية للصلاحيات وأسماء السجلات التقنية قبل ترحيل أول قاعدة.

## كيفاش نراجعو المخطط قبل البرمجة

نجربو على الورق خمسة ملفات: كراء عادي مؤدى كاملاً، تمديد داخل موسم جديد، تبديل بعد عطب، حادث مع ضمان وتعويض تأمين جزئي، وقرض مع قسط مؤدى جزئياً ومصروف موزع على سيارتين. كل مبلغ أو موعد خاص يكون عندو مصدر واحد معروف.

النتيجة المطلوبة هي أن نقدروا نجاوبو: شكون دار العملية، علاش، شحال المستحق والمحصّل، فين السيارة، وشنو باقي مطلوب. من بعد نعتمدو مصفوفة الحالات والصلاحيات، ونراجعو الشاشات قبل التنفيذ. ما كاينش ترحيل أو نشر ضمن هاد الخطوة.

هاد المراجعة المكتبية موثقة فـ[أمثلة المسارات والحسابات المتوقعة](workflow-scenario-review-ar.md)، مع الفروق اللي خاص التنفيذ يحميها وحدود الحساب اللي مازال ما تحسماتش. المراجعة ماشي نتيجة اختبارات برنامج.
