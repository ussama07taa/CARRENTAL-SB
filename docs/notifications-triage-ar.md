# تنظيم التنبيهات

التغيير خاص بواجهة الجرس عبر notifications=1. يبقى عرض المتابعة الكامل في لوحة القيادة مستقلاً.
- Urgent: المتأخر وإجراءات اليوم.
- À traiter: الطلبات والملفات الناقصة؛ الوثائق الناقصة مجمعة حسب السيارة وفتحها يعرض جميع وثائق السيارة.
- À venir: المواعيد القادمة.
- عدد الجرس: العاجل + الطلبات التي تنتظر المعالجة، وليس الرسائل غير المقروءة. النواقص العامة لا تضخم هذا العدد.
- لا حذف ولا تعديل بيانات أو تغيير شروط الجاهزية؛ لا تغيير حسابات مالية.
- تحقق: 10 اختبارات PostgreSQL ناجحة (161 تحققاً)، TypeScript، عرض متصفح بواجهات API وهمية عند 320/768/1280. نسخة الملفات السابقة محفوظة محلياً قبل نشر 3108.
